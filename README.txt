MochiCloner Mini - complete Android project (builds on GitHub Actions)

1. Create a new GitHub repo, upload EVERYTHING in this folder (keep .github/ folder).
2. Go to the Actions tab -> "Build APK" -> wait ~3-5 min (it also runs on every push).
3. Open the finished run -> Artifacts -> download MochiCloner-debug-apk -> unzip -> app-debug.apk
4. Copy to phone, tap to install (allow "install unknown apps").
Note: the app loads Tailwind/Leaflet/fonts/map tiles from the internet, so it needs a connection.
